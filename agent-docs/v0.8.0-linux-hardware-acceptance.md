Preliminary `aconnect` and Mido enumeration saw a KATANA client with MIDI 1/2/3
ports. Read-only onboarding selected the main MIDI 1 port independently in both
directions and saved the coordinate-free selector. Doctor subsequently returned
READY with six production-approved v4.00 definitions and no MIDI commands sent.
These are readiness observations, not amplifier firmware proof or live pedal
acceptance.

A bounded 30-second active startup observation opened the saved input before the
output, received six checksum-valid/address-matched replies in about 113 ms, and
reported six requests, six replies, zero retries/timeouts/checksum failures, and
one completed state synchronization. The observed flags were Boost on, Mod off,
FX off, Delay on, Reverb on, and Effect Loop on. The session ended normally at
the duration limit and logged no action. A human must still compare those values
with the amplifier before the first functional item can pass.

version/help/validation/replay, and removed-module smoke checks. The Windows
