## Required acceptance sequence

- [ ] Run `./onboardPedalboard.ps1` and confirm a saved profile is checked READY
      without opening a MIDI output or sending a message.
- [ ] Run `./diagnosePedalboard.ps1` and confirm fresh READY discovery.
- [ ] Run `./recordPedalboardSession.ps1 -DurationMinutes 5` and verify the JSON
      log ends with `stopReason: duration-limit` and no Katana commands.
- [ ] Run `./recordPedalboardSession.ps1 -Active -DurationMinutes 5`; confirm A
      Panel/PC4, B A:CH2/PC1, C Booster/Mod/CC16, and D Delay/FX/CC17, then
      restore the original sound/effect state.
- [ ] Repeat the active smoke test with `-LedFeedback`; confirm momentary LEDs
      do not claim amplifier-state synchronization.
- [ ] While an active session is running, reconnect the Katana, then press a
      mapped button and record the resulting `katanaReconnects` metric.
- [ ] In a separate active session, reconnect the BlueBoard and confirm routing
      resumes without restarting the process; record `reconnects`.
- [ ] Stop an active session with Ctrl+C; confirm final metrics and clean return.
- [ ] Run one active `-DurationMinutes 60` rehearsal session and attach or cite
      its ignored JSON log. Review action and transport failures before passing.
